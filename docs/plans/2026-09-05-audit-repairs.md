**Design constraints**

- Candidate isolation must cover filesystem and process side effects as well as SQLite. Do not trust arbitrary roots/tasks/spool paths recovered from a copied database; a validation-only mode must prevent them from running. Candidate failure must not mutate production even when migrations or initialization fail.
- Acquire one state-directory ownership lock before database initialization; reject a second owner regardless of port. Handle crash cleanup safely without PID reuse assumptions or unlinking another owner's lock.
- Preserve ordinary terminal ownership, Unix-account enforcement, Cloudflare audience validation, file roots, CORS, cleanup and rate limits. Do not turn on OS isolation as a side effect of dependency or UI repairs.
- Browser write protection must work behind configured trusted proxies and origins, reject forged cross-origin requests, and keep explicitly authenticated non-browser callers supported. Do not permit an arbitrary Host header to establish trust.
- Upload limits apply to actual streamed bytes before multipart parsing; downloads must close descriptors and release budgets on cancellation. Existing broker protocol limits remain enforceable.
- Trash/restore must operate through the same user and granted root as the original file action. Keep an immutable owner/root/mapping binding; never overwrite a replacement file or let a stale grant/Unix mapping recover data into a different identity.
- Inert settings must not silently activate previously stored network auto-fetch or disable confirmations. Make any required re-activation clear. Existing session history must not unexpectedly shrink during migration.
- Preserve existing `web/vendor/` assets. New pinned assets belong in a separate generated location with source/version/license manifest and deterministic build verification.
- Backups have explicit age/restore checks. Off-host destination is pending owner input; local backup and restore work proceeds independently. No secret material belongs in logs or repository evidence.
